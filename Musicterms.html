💾 存檔匯入 / 匯出（跨平台）

• 匯出：下載 JSON 檔，包含所有牌組 + 掌握度進度 + 答題歷史。

• 匯入：選擇 JSON 檔，自動合併。新牌組直接加入；同 ID 牌組取較新版本；掌握度取較高等級。

• 跨平台：手機學完 → 匯出 → 傳到電腦 → 匯入繼續學。只要有這個 HTML + JSON 就能繼續。

ℹ️ 使用说明

• Upload PDF：支持含文字层的 PDF。系统会自动按空格/制表符/分隔符识别术语对。

• Paste Text：每行一条，用 Tab、多个空格或「-」「:」分隔术语和含义。

• Manual：逐条输入，可随时增删改。

• 每个牌组可单独设置术语朗读语言（意/法/德/英/中等）。

• 所有牌组数据保存在浏览器本地，不会上传到服务器。

🎵 音樂術語閃卡 + 盲盒獎勵系統
一個邊學邊玩的互動閃卡工具——答題拆盲盒，收集知識碎片
💡 第一次使用？選擇牌組 → 進入「閃卡」模式翻卡學習 → 答對題目就會收到盲盒獎勵。每 5 張翻卡也會觸發獎勵。往左/右滑動盲盒消息可以關掉它。
🎴 六種學習模式
🎴
閃卡：翻卡學習。點擊卡片翻面，按 S 鍵朗讀術語，空格鍵翻轉。每翻 5 張卡 → 觸發盲盒獎勵。
📖
學習：4選1選擇題。看術語選答案，即時反饋正確/錯誤，答錯自動重做。
✏️
書寫：看術語拼寫答案，即時批改。
📝
測試：選擇題測驗，限時作答，答對獎勵盲盒。
🎯
配對：將術語和釋義配對消除。
📋
列表：瀏覽所有卡片，可標記已掌握。
🎁 盲盒獎勵系統
🎲
答對題目 → 觸發盲盒。盲盒有 15 種類型，分為 5 個稀有度：
⚪
普通（50%）：簡單肯定、搞笑、荒謬比喻
🟢
不常見（28%）：冷知識、詞源考古、意想不到的連結
🔵
稀有（14%）：迷你故事、數字冷知識、地理連結
🟣
史詩（6%）：歷史第一、反直覺、頓悟時刻、時光機
🟡
傳說（2%）：彩蛋、命運骰子——極稀有！
👆
滑動消失：盲盒消息出現在頂部橫條，向左或向右滑動即可關閉。點擊可釘住。
📬
消息記錄：打開☰選單 → 點「消息記錄」查看歷史消息（最近 200 條）。
🏆 等級與成就
📊
等級：累計答對題數提升等級，共 15 級（🎲盲盒新手 → ✨盲盒星空）。點擊頂部的等級圖示查看等級地圖和進度條。
🏅
成就：16 個成就可解鎖，包括連擊達人、全類型收藏、翻卡大師等。
🎨
收藏：點擊等級圖示 → 打開收藏面板，查看你拆過的盲盒種類、數量、未收集的清單。
⚙️ 其他功能
☰
漢堡選單：右上角☰按鈕 → 查看進度統計、切換音效/語言/深色模式。
🌐
中英文切換：UI 文字支援中英文切換，術語內容不變。
🔊
語音朗讀：使用瀏覽器 TTS 朗讀術語和釋義（支援義大利語語音）。
🗂️
牌組管理：可創建/導入自訂牌組。盲盒內容會根據牌組主題自動切換（音樂牌組 → 音樂知識池，其他 → 通用知識池）。
💾
自動儲存：所有進度（等級、成就、收藏、連擊紀錄、掌握度）自動存在瀏覽器 localStorage 中，下次打開自動恢復。
📊
儀表板：首頁顯示每個牌組的掌握度分佈（🔴未見過→✅已掌握），以及待復習和弱點卡片數量。
🧠
全卡測驗：逐張翻卡自評「會/不會」，系統追蹤掌握度並安排間隔複習（1天→3天→7天→14天→30天）。
⚡
弱點專練：只抽掌握度≤🟡的卡片集中衝刺。
📤
存檔匯出/匯入：牌組管理→導出 JSON（含牌組+掌握度），跨裝置匯入時自動合併進度（取較高等級）。
