📈 四週進度：規律 ＞ 時長

第1週：每次練30分鐘後做3–5分鐘（目標＝變成流程一部分）→ 第2–3週：5–10分鐘 → 第4週起：10–15分鐘，平日用A、深疲勞日用B。日日3分鐘 ＞ 一週一次30分鐘。

🚀 啟動急救卡

Practice Starter Kit・對付「知道要練但係唔想開始」・5分鐘內上弓

🔍 第一步・診斷：你今日係邊種「唔想開始」？

拖延唔係懶，係大腦嘅保護反應——對症先至落藥：

類型內心OS對症解法
完美主義型「今日狀態唔好，拉都係難聽」答應自己「今日只摸琴，唔使拉好聽」
任務過大型「要練90分鐘，好似好攰」只承諾5分鐘，之後想停就停
能量不足型「好攰，完全冇動力」先切🧘冥想卡做⚡微重啟語音版，再決定
🪜 第二步・微行動階梯：只需要「啟動」，唔需要「完成」
規則：做完一級，先問自己「想繼續嗎？」——想就上，唔想都可以停。但通常你會想繼續（動態慣性）。
📍 第三步・環境觸發點：靠環境，唔靠意志力（設定一次，自動啟動）
💭 卡住嗰陣・30秒情緒覺察

想拖延時，停一停問自己：「我而家真正感覺到嘅係咩？」
係怕拉得唔好？（完美主義）　係覺得任務太大？（過大）　定係純粹攰？（能量）
接納情緒，唔好壓抑——然後用階梯第1級回到正軌。

🏆 小勝利迴路：打勾就係燃料

每完成一個微步驟就打勾——呢頁階梯、「🗓️ 每日流程」、「🎯 高效練琴檢核卡」全部會自動記住。
大腦鍾意被獎勵：視覺化嘅完成紀錄，就係行動力嘅永續燃料。
唔使大張旗鼓慶祝，一句「做得好」就夠。
